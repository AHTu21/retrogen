# Мастерская, биржа, валюта — дорожная карта

Документ развивает идеи из обсуждения **без** реализации сервера авторизации в текущем спринте.

## Мастерская (Workshop)

- Каталог **шаблонов ретро** (тексты стикеров, наборы рамок, пресеты блоков).
- **Конструктор схем**: линии, стрелки, пулы, swimlane (позже).
- Публикация в общий каталог с лицензией «свободно / с указанием автора».

## Общий «магазин» идей

- Не обязательно монетизация: сначала **библиотека** с тегами (`#retro`, `#5whys`, `#team-health`).
- Рейтинг и «скачали N раз».

## Биржа

- Карточки предложений: тип (услуга | знание | вещь), описание, контакт, таймзона.
- Фильтры по языку и теме.
- Опционально «безопасная сделка» позже (эскроу вне MVP).

## Внутренняя валюта (черновик экономики)

| Элемент | Идея |
|--------|------|
| Название | **Ретро-монеты** (рабочее) |
| Заработок | Завершённое ретро, приглашённые участники, полезные шаблоны в мастерской |
| Т трата | Темы-премиум, косметика, выделение в бирже |
| Антифрод | Лимиты, ручная модерация при подозрении на накрутку |

## Косметика интерфейса (видят другие)

- Сервер хранит `cosmeticProfile`: спрайты в рамках лимита, CSP, MIME-check.
- В комнате рядом с именем — **бейдж** или превью курсора/рамки «как стим-профиль».
- Фолбек: локальный `/profile` (как сейчас), пока аккаунта нет.

## Идеи для левой панели (кроме шаблонов и схем)

- Быстрые **структуры**: «2 колонки», «стар/стоп/продолжить», таблица рисков.
- **Линейка времени** (одна ось на плоскости).
- **Голосовалка-мини** (один вопрос) без отдельного блока ретро.
- **Стикеры-стикеры**: короткий текст из пресета («блокер», «нужна помощь»).
