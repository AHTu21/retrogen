# Чеклист фич (живой документ)

Итерации самопроверки зафиксированы ниже по фазам. Статус: **Фаза A** частично или полностью в коде после текущего PR; **Фаза B–D** — проектирование без полной реализации.

## Самопроверка — итерация 1 (объём и риски)

- [x] Слои стикеров **внутри одного блока** остаются локальными (ограничение DOM): глобальный порядок гарантирован между **блоками** и **стикерами free-canvas** и **рамками схем** / **таймерами** через единое поле `layerZ` / `z`.
- [x] Цвет фона блока/стикера через `planeState` — без миграции Prisma; совместимо с существующим PATCH plane.
- [ ] Полный «косметический» обмен между пользователями (как Dota 2) требует сервер профилей и антивируса для загрузок — вынесено в Фазу D.

## Самопроверка — итерация 2 (консистентность данных)

- [x] `cardStyles` / `blockStyles` / `planeShapes` / `gadget.layerZ` сериализуются в `PlaneStateDto` и участвуют в debounced PATCH.
- [x] Откат вида доски (Ctrl+Z) включает стили и фигуры, если они уже были в snapshot-цепочке.

## Самопроверка — итерация 3 (UX)

- [x] ПКМ: цвет фона + пресеты + сброс; подменю не закрывает доску без клика.
- [x] Профиль — только локально (`localStorage`), не ломает гостевой вход в комнату.

## Фаза A — сделано в продукте (MVP)

- [x] Левая панель: **шаблоны** стикеров (текст HTML) + **схемы** (рамки на плоскости, перетаскивание, слой).
- [x] ПКМ стикер/блок: **цвет фона** (picker + пресеты + сброс).
- [x] **Слои**: «на передний / на задний» учитывают блоки, стикеры, таймеры и рамки; новые сущности получают `layerZ` выше текущего максимума.
- [x] Страница **`/profile`**: ФИО, контакт, цвет фона плоскости, оттенок шапки, стиль курсора, фон-обои (data URL, лимит размера).
- [x] Страница **`/workshop`**: заглушка + ссылка на дорожную карту.
- [x] **`docs/COMMUNITY_ROADMAP.md`**: мастерская, биржа, внутренняя валюта — фазы B–D.
- [x] Верификация: `npm run build` (client `tsc` + Vite, server `tsc`) — успешно.
