## Карта реализованного функционала (по блокам)

Краткая сводка того, что уже есть в коде; детали правок по релизам — в `CHANGELOG.md`. Нумерация секций ниже совпадает с разделами чеклиста.

### Лобби и главная

- Список комнат на сервере: **GET `/api/rooms`** (query `q`, `status`, `limit`), обновление лобби по сокету **`joinLobby`** / **`lobby:patch`** при создании и завершении ретро.
- На клиенте: главная с поиском и фильтрами; **недавние** и **избранное** в `localStorage` (не синхронизируются между устройствами; перенос в профиль пользователя на сервере — см. **раздел 12**).

### Доска и редактирование (раздел 1)

- Стикеры: CRUD, перетаскивание внутри блока и по canvas, ресайз, z-order, контекстное меню.
- Плоскость: зум, панорама, undo/redo **состояния вида** (не путать с отменой набора текста в стикере).
- Блоки ретро: создание, перемещение, режим «в руке», частично оптимистичные патчи без полного refetch.
- Сброс комнаты на сервере с явным подтверждением.

### Спец-блоки (раздел 2)

- Звездочка спринта, шкала «оцените ретро», отдельные ответы «одна вещь улучшить», разминка с одним голосом, колонки хорошо/плохо/улучшить.

### Изображения на плоскости (раздел 3)

- Вставка из буфера и с диска; трансформации на canvas; слой относительно блоков/стикеров; подпись и поворот на 90°.

### Гаджеты на плоскости (зачаток раздела 10)

- Таймер с обратным отсчётом в `planeState` (синхронизация с сервером).

### Редактор стикеров (раздел 4)

- Быстрая вставка эмодзи с панели; подсказка **контраста** цвета текста и маркера (WCAG-ориентир).
- Реакции на стикер (пресеты эмодзи, счётчики, один голос на тип от участника, синхронизация через API и сокет).
- Форматирование: начертание, выравнивание L/C/R и T/M/B, цвета, шрифт/размер, списки, таблица (базовая + строки/столбцы), колонки `║2`/`║3`.
- Расширения: ссылки, super/sub, кисть формата, очистка формата, регистр, цитата, код, HR, перенос слов, моно/¶.
- Типографика в поле: межстрочный интервал, padding, gap абзацев (÷ / ⊡ / ¶).
- Панель: стек отмены для действий панели (`↶`/`↷`); plain paste и кнопка «T»; Ctrl+V из rich — в plain; лимит длины HTML и предупреждение; MD в буфер; spellcheck; тост «Сохранено на сервере».
- UX панели: не закрывается при клике по инструментам; согласование фокуса с `contentEditable`.

### Завершение ретро и отчёт (раздел 5)

- Статус **`ended`**, дата `endedAt`; кнопка **«Завершить ретро»** и страница **`/r/:slug/summary`**: сводка по блокам, средняя оценка, one thing, звёзды, разминка, **action items** (модель на сервере), экспорт **JSON** / **Markdown** в буфер, **печать** (PDF через диалог браузера).

### Синхронизация плоскости (раздел 1 — реализованная часть)

- Состояние плоскости (зум, смещение, раскладки блоков/стикеров, z-order, мемы) хранится в **`planeStateJson`** и версионируется полем **`planeVersion`**; сохранение через **PATCH `/api/rooms/:slug/plane`**, рассылка **`room:patch` / `plane.state`**. Конфликт версий → 409 и подтягивание серверного снимка. Конфликт текста стикера: **PATCH карточки** с опциональным **`expectedUpdatedAt`**.

### Справка и «О программе» (клиент комнаты)

- **Справка:** компактное окно, перетаскивание, полный экран, минимизация в иконку в шапке; прокрутка колёсиком внутри окна не меняет зум доски.
- **О программе** (кнопка со значком «i» **справа** от справки): заголовок, **версия клиента** (`package.json` workspace client), ниже — содержимое **[CHANGELOG.md](./CHANGELOG.md)** (импорт при сборке как текст `?raw`), с человекочитаемыми формулировками по разделам. При открытии окна «О программе» справка сворачивается; **Esc** сначала закрывает «О программе», затем обрабатывает справку. Новые пункты релиза описывать в CHANGELOG (в т.ч. блок «понятным языком» для пользователей), затем при необходимости дублировать кратко в карте ниже.

### Сервер, данные, качество (разделы 0, 8, 9)

- Монорепо, Prisma, PostgreSQL, Socket.IO, Docker; фильтрация темы по deny-list, длине и опциональному env **списку подстрок**; лог отклонённых тем.
- Черновик **[docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md)** для production.

### Виджеты / гаджеты (раздел 10) — в проработке

- Мини-инструменты на плоскости (таймер, random, мини-опросы и т.д.), единая модель расширения и синхронизация с доской.

### Документы и аналитика (раздел 11) — в проработке

- Загрузка протоколов/отчётов для контекста, поиск, опционально LLM-анализ; связь загрузок с сессией ретро.

## 12) Персональные настройки интерфейса (привязка к аккаунту) и гости

**Запланировано доработать.** Сейчас большая часть «индивидуальной гибкости» UI хранится только в браузере (`localStorage` / кэш вкладки), без записи в БД и без переноса между устройствами.

### Цель

- **Авторизованный пользователь:** устойчивые предпочтения интерфейса хранить **на сервере**, привязанными к аккаунту; при входе подтягивать, при изменении — сохранять (достаточно **обычного HTTP**, debounce; **не** real-time и **не** рассылка другим участникам комнаты — эти данные видит только владелец аккаунта).
- **Гость (без логина):** те же классы настроек — **только локально** (кэш / `localStorage`); часть возможностей **только после авторизации** (серверный состав комнаты, «мои» списки на сервере и т.д. — по мере появления API).

### Принципы (зафиксировать при реализации)

- В БД складывать **устойчивые** предпочтения, а не каждый эфемерный флаг UI (открытые модалки, drag в процессе).
- Не путать с **состоянием доски** (`planeState`, карточки) — там общий источник правды и сокеты.
